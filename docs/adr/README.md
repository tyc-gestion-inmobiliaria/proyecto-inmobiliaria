# Registro de decisiones (ADR)

Cada decisión de arquitectura en un archivo, con su contexto, la decisión y sus consecuencias. Una decisión aceptada no se edita para cambiarla: se escribe un ADR nuevo que la reemplaza y el viejo pasa a *reemplazada por ADR-NNN*.

Los decide el líder técnico (Guía de trabajo §6.4). Para agregar uno: copiar el formato de los existentes con el número siguiente, y abrirlo en un PR.
