# Marca de T&C

Logo de T&C (Gestión y Administración Inmobiliaria S.A.C), tomado de su web
(tc-inmobiliaria.com, `version-negro.png`) para darle su cara a la app.

- `logo.png`: el logo completo, recortado, para el acceso.
- `isotipo.png`: solo el edificio con "T&C", para la barra y el ícono.

Es la marca del cliente: si entregan el original en vectores, se reemplaza.
